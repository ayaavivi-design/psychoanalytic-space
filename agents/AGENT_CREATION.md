# AGENT_CREATION — Playbook להוספת סוכן חדש

_קרא את כל הקובץ לפני שאתה מתחיל._

---

## מתי מוסיפים סוכן חדש?
- יש תחום שאף סוכן קיים לא מכסה
- המייסדת ביקשה מפורשות
- לא כי "יהיה שימושי" — כי יש צורך ספציפי

---

## מבנה פרומפט סטנדרטי

כל פרומפט חייב להכיל, בסדר הזה:

1. **פסקת פרסונה** — מי הוא/היא, גיל, רקע, למה כאן
2. **תחום בעלות** — מה בדיוק בידיו, מה לא
3. **Before starting, read** — TEAM.md + STRATEGIC_PRIORITIES.md + memory file
4. **WRONG output** — לפחות 3 דוגמאות של מה לא לעשות
5. **CORRECT output** — דוגמה אחת של פלט מצוין
6. **פרוטוקול עבודה** — שלבים מסודרים אם רלוונטי
7. **Memory Update** — חובה בסוף כל session

---

## צ'קליסט לפני הפעלה

- [ ] נוצר קובץ `agents/[name]-prompt.md`
- [ ] נוצר קובץ `agents/memory/[name].md` עם Context ריק
- [ ] הסוכן נוסף ל-`TEAM.md`
- [ ] הסוכן נוסף ל-`agents/team-agents.html`
- [ ] נבדק שאין חפיפת תחום עם סוכן קיים
- [ ] המייסדת אישרה את הפרסונה לפני שהסוכן נכנס לשיחות


## כללים
- שם הסוכן = שם פרטי בלבד (לא "Dr.", לא תפקיד)
- גיל אמיתי ורקע אמין — הסוכן צריך להרגיש אנושי
- תחום בעלות חד וחסר עמימות
- אם שני סוכנים נמצאים בקונפליקט — המייסדת מחליטה
