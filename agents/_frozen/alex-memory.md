- **unit economics**: עלות per user = עלות API Claude + Supabase + Vercel — לחשב תמיד.
- **מחיר 69 ₪**: עדיין מוצע, לא סגור. Margin תלוי בנפח.
- **B2B שינוי יחידות כלכלה**: אם המטפל/ת משלם — שאלת הליבה היא משלם/ת מכיסו או מגלגל/ת למטופל (WTP/ACV שונה לחלוטין). margin ~95% בשני המודלים; הסיכון הוא lock-in/retention, לא עלות.
- **Jimini benchmark (יוני 2026): לא מודל לחיקוי בשלבנו.** Jimini = B2B2C מוסדי + EHR + reimbursement (CMS) + $25M. דורש הון, אינטגרציות, מחזור מכירה 6-18ח'. **הכרעה: מטפל/ת בודד/ת (לא ארגון) + מנוי ישיר (לא reimbursement).** סולו: CAC נמוך (~₪300, קהילה צפופה), מחזור קצר (החלטה עצמאית), WTP גבוה (פגישה ₪350-500), ACV ~₪1,200/שנה, LTV/CAC≈8. reimbursement לא קיים בישראל ודורש RCT+שנים — להתעלם בשלב זה.
- **תנאי סף לפני תמחור: אימות retention.** המודל החולף מוחק lock-in → אם churn>7% חודשי, LTV מתמוטט. חייב Mom-Test + מדידת חזרה שבועית 2-3 שבועות לפני כל מספר מחיר. אין חזרה ספונטנית = אין עסק מנוי.
