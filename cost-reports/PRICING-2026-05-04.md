## מבנה Stripe

### מוצרים ליצירה ב-Stripe Dashboard

```
Product: Between Pro Monthly
  Price: ₪49.00 ILS / month
  Billing: monthly
  Trial: 14 days

Product: Between Pro Annual
  Price: ₪470.00 ILS / year
  Billing: yearly
  Trial: 14 days
  Savings badge: "חסכו ₪118 בשנה"
```

### טבלת Supabase — users

להוסיף שדות:
```sql
stripe_customer_id    TEXT
stripe_subscription_id TEXT
plan                  TEXT DEFAULT 'free'  -- 'free' | 'pro'
plan_expires_at       TIMESTAMPTZ
conversations_this_month INT DEFAULT 0
trial_ends_at         TIMESTAMPTZ
```

### לוגיקת חסימה

| מצב | פעולה |
|-----|--------|
| free + conversations_this_month < 5 | מאפשר שיחה |
| free + conversations_this_month >= 5 | חוסם + מציג upsell |
| pro + plan_expires_at > now() | מאפשר הכל |
| trial + trial_ends_at > now() | מאפשר הכל |
| trial_ends_at פג | מעביר ל-free אוטומטית |

### Webhook events לטפל בהם

```
customer.subscription.created   → עדכן plan = 'pro'
customer.subscription.deleted   → עדכן plan = 'free'
customer.subscription.updated   → עדכן תאריך פקיעה
invoice.payment_failed          → שלח אימייל + חסום אחרי 3 ימים
```
